· 首次启动会自动建表并写入演示数据（1 个管理员、3 个分类、4 道菜品、1 个套餐）。删除 data 目录后重启即可恢复到初始状态。
· 微信登录 / 微信支付 / 退款 相关接口依赖真实商户号与证书，在离线桌面环境会返回失败，属预期行为。
· 本项目为教学演示用途，默认配置中的密钥与账号口令不应直接用于生产环境。
