苍穹外卖 · 桌面版（免安装）v1.1.0
========================================

一、启动
  1. 双击 start.bat        —— 带控制台窗口，可看到启动日志（推荐首次使用，可看到启动日志）
  2. 双击 start-silent.vbs —— 无窗口静默启动，13 秒后自动打开浏览器
  启动完成后浏览器会打开 http://localhost:8080 ，自动进入「管理后台」界面。

二、界面入口
  管理后台：http://localhost:8080/manage/index.html （根路径会跳转到这里）
  说明页  ：http://localhost:8080/about.html         （接口速查与环境说明）
  接口文档：http://localhost:8080/doc.html           （Knife4j，可在线调试）
  管理端账号：admin / 123456

三、管理后台可做什么
  工作台    —— 营业额、有效订单、完成率、客单价、新增用户；待接单/待派送/已完成/已取消统计
  订单管理  —— 按订单号、手机号、状态查询；接单、拒单、派送、完成、查看明细
  菜品管理  —— 分页查询、新增、编辑、删除、起售/停售（含分类筛选）
  套餐管理  —— 分页查询、起售/停售、删除
  分类管理  —— 新增、编辑、删除、启用/禁用
  员工管理  —— 新增、编辑、启用/禁用（新增账号默认密码 123456）
  营业状态  —— 一键切换营业中/已打烊（同步到用户端 /user/shop/status）

四、目录说明
  app\      程序主体（sky-take-out.jar）
  runtime\  内置 Java 17 运行时（无需自行安装 JDK）
  upload\   上传的图片存放目录
  data\     H2 数据库文件（sky_take_out.mv.db），删除该目录即可重置为初始演示数据
  logs\     运行日志

五、常见问题
  1. 端口被占用：设置环境变量 SKY_PORT 后再启动，例如 set SKY_PORT=8081
  2. 启动窗口一闪而过：确认杀毒软件未拦截 runtime\bin\java.exe
  3. 浏览器显示无法访问：等待 15 秒后刷新；仍失败请查看 logs\sky-take-out.log
  4. 管理后台提示登录已失效：刷新页面重新输入 admin / 123456
  5. 微信登录/微信支付相关接口会失败：桌面离线环境无微信商户配置，属正常现象

六、技术栈
  Spring Boot 3.5.16 · Java 17 · MyBatis · H2（MySQL 兼容模式） · Knife4j 4.5.0
